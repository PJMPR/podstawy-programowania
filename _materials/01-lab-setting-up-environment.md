## Zadania laboratoryjne

Materiały do tego laboratorium będą dostępne tutaj. Na tym etapie znajduje się tylko placeholder.

### Zadania do wykonania:
1. Zainstaluj Visual Studio Community lub Visual Studio Code
2. Zainstaluj .NET SDK w wymaganej wersji
3. Utwórz nowy projekt konsolowy C#
4. Napraw/zmodyfikuj program Hello World
5. Skompiluj i uruchom program
6. Eksperymentuj ze zmianą komunikatu

- Spróbuj uruchomić program z linii poleceń
- Zapoznaj się z kodem wygenerowanym przez IDE
