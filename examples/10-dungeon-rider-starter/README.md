# DungeonRider — starter laboratorium 10

Starter jest działającym rozwiązaniem laboratorium 09 przemianowanym na `DungeonRider`.
Kod celowo korzysta ze statycznych metod, tablicy `char[,]` oraz osobnych zmiennych
`playerX` i `playerY`. Podczas laboratorium 10 zostanie zrefaktoryzowany do klas i obiektów.

```powershell
dotnet build .\src\DungeonRider\DungeonRider.slnx
dotnet run --project .\src\DungeonRider\DungeonRider.App\DungeonRider.App.csproj
```
