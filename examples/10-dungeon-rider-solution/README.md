# DungeonRider — rozwiązanie prowadzącego laboratorium 10

Końcowa, obiektowa wersja startera z Lab09. Obejmuje klasy `DungeonMap`, `Player`
i `DungeonGame`, konstruktory, hermetyzację stanu, ruch gracza, kolizje i zbieranie skarbów.

```powershell
dotnet build .\src\DungeonRider\DungeonRider.slnx
dotnet run --project .\src\DungeonRider\DungeonRider.App\DungeonRider.App.csproj
```
