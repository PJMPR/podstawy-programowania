# Pierwsza mapa lochu — starter

Kompilowalna baza dla studentów do laboratorium 09. Każde zadanie uruchamia się z menu, a miejsca wymagające implementacji oznaczono komentarzem `TODO`.

```powershell
dotnet run --project .\examples\09-first-dungeon-map-starter\FirstDungeonMap.Starter.csproj
```

Zachowuj konwencję `map[y, x]`: `y` oznacza wiersz, a `x` kolumnę. Rozwiązuj zadania kolejno, ponieważ następne korzystają z metod uzupełnionych wcześniej.
